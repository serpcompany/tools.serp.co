# OSS library and tool research backlog

This page retains owner-supplied open-source projects and repository indexes
that may be useful when evaluating future Tool processor families. Entries are
research leads only. Inclusion does not establish that a project is maintained,
secure, correctly licensed for our use, browser-compatible, semantically
correct, or approved for implementation.

Before using an entry, review its exact operation coverage, browser and
Cloudflare compatibility, package boundaries, resource behavior, cancellation,
security posture, license and redistribution terms, maintenance activity, and
the independent fixtures and validators needed to verify its outputs. Active
evaluation or implementation work must be authorized and tracked in GitHub
Issues.
