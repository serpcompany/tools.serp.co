PROTOTYPE — Can a PNG prove its visible table content?

This throwaway demo tests one question for csv-to-png: can the browser render a readable table and then independently reopen the delivered PNG and recover the exact headers, rows, and cells from pixels alone? It uses a deliberately constrained bitmap font so verification does not need OCR, a server, or trust in the renderer.

Expected table: NAME / ROLE, then ADA / ENGINEER and GRACE / SCIENTIST. A valid result must survive PNG encoding, ImageBitmap decoding, and pixel-level glyph recovery.
